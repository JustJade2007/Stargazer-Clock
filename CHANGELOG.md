## [Unreleased]

### Planned
- **Starry Cosmic Backdrop**: Dynamic starry background canvas with subtle twinkling and depth effects, tailored for desktop backdrops and focus sessions.
- **Semicircle Dial Arc Interface**: Radial arc visualization indicating progress across timeframes, shifts, and timers.
- **Multi-Mode Time Tracking**:
  - Current Clock (12h/24h with customizable seconds and timezones).
  - Timeframe / Shift Tracker (visual timeline progress across defined work shifts).
  - Countdown Timers with configurable sound alerts and labels.
  - Precision Stopwatch with split laps.
  - Multi-Widget Combined Mode.
- **Local Cookie Persistence**: Automatic retention of custom intervals, themes, and timer presets via client-side cookies.
- **Multi-Platform Deployment Pipeline**:
  - Hosted static deployment on GitHub Pages.
  - Standalone local web server runner.
  - Portable desktop executable (`.exe`).
