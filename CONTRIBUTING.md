# Contributing to Stargazer Clock

Thank you for your interest in contributing to **Stargazer-Clock**! We welcome bug fixes, design improvements, new features, and documentation enhancements.

---

## Code of Conduct

Please treat all maintainers and contributors with respect, courtesy, and empathy.

---

## How to Contribute

### 1. Reporting Bugs
- Search existing [Issues](https://github.com/JustJade2007/Stargazer-Clock/issues) to verify the bug has not already been reported.
- If not already logged, use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md) to open a new issue.
- Include clear reproduction steps, screenshots (if visual), and browser/OS versions.

### 2. Suggesting Features
- Use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
- Clearly explain the intended use case and how it aligns with the cosmic ambient focus of Stargazer-Clock.

### 3. Pull Requests
- Fork the repository and create a branch from `main` (or active development branch).
- Keep changes focused and minimal: one feature or fix per pull request.
- Ensure all code runs cleanly with no console errors or broken styles.
- Fill out the [Pull Request Template](.github/pull_request_template.md) completely upon submission.

---

## Code Style & Guidelines

- **Vanilla Web Technologies**: Prioritize standard HTML5, CSS3, and JavaScript/TypeScript without unnecessary bloated frameworks unless agreed upon.
- **Visual Excellence**: Ensure changes maintain the starry celestial aesthetic, smooth transitions, and high readability.
- **Privacy & Local State**: Do not add remote tracking, analytics, or third-party tracking scripts.
- **Clean Commits**: Write descriptive, concise commit messages following standard conventions (e.g. `feat:`, `fix:`, `docs:`, `style:`).
