# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security and integrity of this project seriously. Because **Stargazer-Clock** runs as a client-side web application and local desktop tool without external backend services, user data is strictly stored locally via browser cookies and client-side storage.

If you believe you have discovered a security vulnerability or exploit:

1. **Do not open a public issue.**
2. Send an email describing the issue with reproduction steps to the repository owner:
   - **Contact**: `jacobhite2007@gmail.com`
   - **GitHub**: [@JustJade2007](https://github.com/JustJade2007)
3. Please provide:
   - Detailed description of the vulnerability.
   - Operating system and browser / runtime version.
   - Proof-of-concept steps or code snippet.
4. You will receive an acknowledgment within 48 hours, followed by updates on remediation steps.
